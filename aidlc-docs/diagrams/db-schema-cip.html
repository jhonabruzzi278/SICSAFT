CIP — schema completo (base de solo lectura)

Las 10 tablas de cip/migrations/, una Postgres separada de la de CORE (RNF-05). No tienen FK entre sí — cada una se puebla de forma independiente desde AgregacionService, releyendo el catálogo de CORE por HTTP en vez de hacer JOIN cruzado de base de datos.
