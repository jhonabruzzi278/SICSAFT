Grafo de revisión

Mapa vivo del repo para la revisión de código y documentación. El tamaño del nodo es su volumen de código; el anillo naranja, los hallazgos abiertos; las aristas, el flujo de datos no negociable captura → CIS → CORE → BPI. Las métricas se recalculan; el criterio se mantiene a mano.

Regenerar con node herramientas/revision-codigo/inventario.mjs --grafo. Las métricas salen de inventario.json (calculado); el estado de avance y los hallazgos salen de estado-revision.json (editado a mano). Están separados a propósito: volver a correr el script no pisa el criterio ya aplicado.
